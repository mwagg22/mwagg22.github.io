FlowPilot EDU

An agent that reads an education RFP, gathers evidence about the vendor, and drafts a proposal a person can check line by line. It can't send or submit anything.

Agent loop
A LangGraph StateGraph. The model chooses each tool from prior observations, capped at 8 calls and 120 seconds.
Models
Gemini, DeepSeek, Ollama, or any OpenAI-compatible endpoint, switchable per run.
Guardrails
Zod-validated output, citations checked against the exact PDF page, a read-only tool allowlist, and a prompt-injection test document.
Tested
4 of 4 live Gemini RFP runs passed, plus 15 regression tests with mocked providers.
Stack
Next.js 15, React 19, TypeScript, Zod, pdf-parse
